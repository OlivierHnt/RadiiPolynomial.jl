Lorenz system

We prove the existence of a periodic orbit of the Lorenz system

\[\dot{u}(t) = f(u(t)) \bydef \begin{pmatrix} \sigma(u_2(t) - u_1(t))\\ u_1(t)(\rho - u_3(t)) - u_2(t)\\ u_1(t) u_2(t) - \beta u_3(t) \end{pmatrix}, \qquad \sigma, \rho, \beta \in \mathbb{R}.\]

Step 1: Formulation

using RadiiPolynomialfunction f(u, params)    σ, ρ, β = params    u₁, u₂, u₃ = u    return [σ*(u₂ - u₁)            u₁*(ρ - u₃) - u₂            u₁*u₂ - β*u₃]endfunction Df(u, params)    σ, ρ, β = params    u₁, u₂, u₃ = u    return [-σ*one(u₁)    σ*one(u₂)    zero(u₃)            ρ-u₃          -one(u₂)     -u₁            u₂            u₁           -β*one(u₃)]endfunction F(x, params, ξ_)    u, τ = unpack(x)    ξ = unpack(ξ_)    return [Derivative(1) .* unpack(u) - τ[1] * f(unpack(u), params),            [adjoint(ξ[1]) adjoint(ξ[2]) adjoint(ξ[3])] * [component(u, j) for j = 1:3]]endfunction DF(x, params, ξ_)    u, τ = unpack(x)    ξ = unpack(ξ_)    M = Matrix{Any}(undef, 2, 2)    L = [Derivative(1)  0*I            0*I         0*I            Derivative(1)  0*I         0*I            0*I            Derivative(1)]    M[1,1] = L - τ[1] * Multiplication.(Df(unpack(u), params))    M[1,2] = [LinearOperator.(-f(unpack(u), params));;]    M[2,1] = [adjoint(ξ[1]) adjoint(ξ[2]) adjoint(ξ[3])]    M[2,2] = [LinearOperator(0);;]    return Mend
