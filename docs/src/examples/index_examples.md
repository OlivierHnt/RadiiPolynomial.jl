# Examples

Each page is a complete computer-assisted proof, built from the same five steps as
[The radii polynomial approach](@ref).

If you are new to the method, work through [Getting started](@ref "A first proof") instead.

## Find your problem

| I want to prove | Start at |
|:--|:--|
| an equilibrium of a vector field | [Equilibria of the Lorenz system](@ref) |
| a solution of an initial value problem | [The logistic equation](@ref) |
| a steady state of a PDE | [Cahn-Hilliard](@ref), then [Nonlinear diffusion](@ref) |
| a periodic orbit | [Non-autonomous ODE](@ref), then [Lorenz system](@ref) |
| a branch of solutions, including through a fold | [Parameter continuation for the cube root](@ref), then [Pseudo-arclength continuation for the cube root](@ref) |
| a manifold of solutions | [Parameter continuation for the Cahn-Hilliard equation](@ref) |
